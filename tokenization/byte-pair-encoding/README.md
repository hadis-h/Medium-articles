# Train a BPE Tokenizer for Your Own Data 

This project demonstrates how to train a Byte Pair Encoding (BPE)
tokenizer from scratch using the Hugging Face `tokenizers` library and the WikiText-103 dataset.

## Installation

Install the required dependencies:

```
pip install -r requirements.txt

```

## Run

Run the training script:

```
python train_bpe_tokenizer.py

```
